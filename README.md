# ITZ FIZZ — Scroll-Driven Hero Animation

A premium scroll-driven hero experience built as a frontend web development assignment.

The project focuses on creating a visually engaging landing page where the hero product, typography, metrics, and supporting elements respond smoothly to the user's scroll position.

## 🚀 Live Demo

https://mrugmayvaidya.github.io/itz-fizz-scroll-animation/

## 📌 Project Overview

ITZ FIZZ is a modern product landing page concept designed around scroll-based storytelling.

As the user scrolls:

- The product moves and transforms across the screen
- Typography changes position, spacing, and opacity
- Product elements rotate and scale
- Statistics transition with the hero
- Sections reveal progressively
- Background elements move at different speeds
- A scroll progress indicator tracks the experience

The goal was to create a smooth, premium interaction while keeping the implementation lightweight and responsive.
